# To Do List en Flutter

Aplicación de lista de tareas inspirada en la imagen de referencia.

## Funciones
- Agregar tareas desde el campo superior.
- Deslizar una tarea hacia la izquierda para mostrar las acciones Editar y Borrar.
- Editar el texto de una tarea.
- Eliminar tareas y recuperarlas con DESHACER.
- Reordenar tareas arrastrando el icono de líneas.

## Ejecutar
Desde la carpeta del proyecto:

```powershell
flutter pub get
flutter run
```

Repositorio de entrega: https://github.com/andreahub1/flutter-run

Antes de entregar, sube estos archivos a tu repositorio y reemplaza la imagen de resultado del PDF por una captura real del emulador si tu docente la solicita.
